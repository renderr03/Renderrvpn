# RenderrVPN

Telegram-магазин VPN для установки на своём VPS. У каждого владельца свой экземпляр бота, база SQLite и одна или несколько панелей 3x-ui. Бот подключается к готовым VLESS-inbound, клиент импортирует подписку в своё VPN-приложение.

## Что входит

- Тариф на 30 дней, оплата Telegram Stars и продление по той же ссылке 3x-ui. Продление оформляется отдельным счётом.
- Пробный период один раз на Telegram-аккаунт. По умолчанию он выключен.
- Выбор локации при первом счёте или активации пробного периода. Продления используют закреплённую локацию.
- Админка в Telegram с ручной выдачей, отключением доступа, диагностикой, сменой цены, возвратами Stars и журналом действий. При сбое бот повторяет синхронизацию с панелью.
- ИИ-помощник по желанию владельца. Он умеет выбирать операции из админки. Перед изменением бот показывает детали и запрашивает подтверждение.

## Требования

- Linux VPS с Docker и Docker Compose v2. Бот получает события Telegram через long polling.
- Новый бот от [BotFather](https://t.me/BotFather) и числовой Telegram ID владельца.
- [3x-ui v3.11.0](https://github.com/MHSanaei/3x-ui/releases/tag/v3.11.0) с рабочим локальным VLESS-inbound на каждой панели. У каждой локации должен быть доступный из контейнера HTTPS-адрес API и доступный клиентам HTTPS-адрес сервера подписок.
- Ссылка на опубликованные условия покупки и Telegram-аккаунт поддержки.

## Установка

Склонируй репозиторий и создай локальную конфигурацию.

~~~sh
git clone https://github.com/renderr03/Renderrvpn.git
cd Renderrvpn
cp .env.example .env
cp nodes.example.json nodes.json
chmod 600 .env
sudo chgrp 10001 nodes.json
chmod 640 nodes.json
~~~

В `.env` укажи `TELEGRAM_BOT_TOKEN`, `ADMIN_IDS` через запятую, `SUPPORT_USERNAME` и `TERMS_URL`. Через `BOT_BRAND` и `BOT_WELCOME` меняются название и приветствие. `PRICE_STARS` и `TRIAL_DAYS` задают начальные значения. После изменений через Telegram действуют значения из базы.

В `nodes.json` заполни настройки для каждой локации.

| Поле | Значение |
| --- | --- |
| `key`, `label` | Стабильный ключ локации и название для клиентов |
| `api_url` | HTTPS-адрес веб-панели с её базовым путём, например `https://panel.example.com/secret`. Бот добавляет `/panel/api/…` |
| `subscription_url` | HTTPS-адрес 3x-ui вместе с путём подписок, например `https://sub.example.com/sub`. Бот добавляет идентификатор подписки |
| `inbound_id` | Числовой ID VLESS-inbound на этой панели |
| `flow` | `xtls-rprx-vision` для настроенного Vision либо пустая строка |
| `token` | Отдельный Bearer-токен 3x-ui с областью `admin` для операций с клиентами. Храни его в файле на VPS |

Дополнительная локация — ещё одна запись в `nodes.json` и перезапуск бота. Если у тебя уже работает развёртывание 3x-ui с несколькими панелями, укажи адрес панели, которая непосредственно обслуживает нужный inbound. Для оплаченных подписок сохраняй ключ ноды и адрес сервера подписок.

~~~sh
docker compose build
docker compose run --rm bot --check-config
docker compose run --rm bot --check-nodes
docker compose up -d
docker compose logs -f bot
~~~

Открой своего бота и отправь `/start`. Владельцу доступны `/admin` и меню «Админка», покупателю — магазин и «Моя подписка». Команда `/paysupport` ведёт к контакту владельца. Для независимой установки передай покупателю файлы проекта и эту инструкцию. Он создаёт собственного бота и использует свои серверы, токены и счета.

## Проверка перед продажами

Для тестирования Stars создай отдельного бота в тестовой среде Telegram и выставь `TELEGRAM_TEST_MODE=1`. Используй отдельный экземпляр Compose, базу и тестовый inbound. Проверь пробную выдачу, платный доступ, импорт ссылки в VPN-приложение, продление и возврат. [Тестовая среда Telegram](https://core.telegram.org/bots/webapps#using-bots-in-the-test-environment)

В проверке ноды бот смотрит состояние Xray и inbound через API панели. Прохождение VPN-трафика проверяется клиентским подключением. Делай резервные копии тома `bot-data` и настроек 3x-ui. Для копии SQLite используй штатный SQLite Backup API либо снимок тома после остановки бота.

## ИИ-помощник

Укажи `OPENAI_API_KEY` и модель с поддержкой Structured Outputs в `OPENAI_MODEL`. Затем открой `/admin` или отправь `/ai проверь ноды`. В запрос к OpenAI передаются текст команды и названия локаций. Стоимость запросов зависит от модели и тарифа API. Все функции админки доступны обычными командами.

## Локальные тесты

~~~sh
python3 -m unittest discover -s tests -v
~~~

Тесты имитируют Telegram и 3x-ui. Они проверяют оплату, продление, повторные события, восстановление после сбоя панели, возврат и проверку прав администратора.
