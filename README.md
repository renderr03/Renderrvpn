# RenderrVPN

VPN-магазин в Telegram для установки на своём VPS. У каждого владельца своя копия платформы, Telegram-бот и база SQLite. Платформа подключается к готовым VLESS-inbound на 3x-ui v3.11.

## Быстрая установка

На Linux VPS с systemd открой терминал от root и вставь одну команду.

~~~bash
curl -fsSL https://raw.githubusercontent.com/renderr03/Renderrvpn/main/install.sh | bash
~~~

Если вошёл обычным пользователем с правами sudo, в конце команды используй `| sudo bash`.

Установщик скачает проект с GitHub, запросит **токен Telegram-бота от [BotFather](https://t.me/BotFather)** и **числовой Telegram ID администратора**. Ввод токена скрыт. На Debian и Ubuntu при необходимости установится Python из системного репозитория. Нужны Python 3.10 или новее и доступ к Telegram и GitHub с VPS.

Бот запускается как системная служба и стартует при перезагрузке VPS. Повторный запуск установщика обновляет программу. База хранится в `/var/lib/renderrvpn`, параметры запуска — в `/etc/renderrvpn/bot.env`.

## Настройка в Telegram

1. Открой бота и нажми **Запустить → Админка → Добавить основную панель 3x-ui**.
2. Отправь адрес панели и Bearer-токен API с правами `admin`. Для панели на том же VPS подойдёт `http://127.0.0.1` с её портом и базовым путём. Для удалённых панелей используй HTTPS. Бот попробует удалить сообщение с токеном после получения.
3. Выбери VLESS-inbound кнопкой. Бот предложит ссылку из настроек подписок панели, если там указан HTTPS-адрес. Иначе отправь адрес сервера подписок вместе с путём, например `https://vpn.example.com/sub`. Клиентам нужен доступ к этому адресу.
4. Проверь название, режим VLESS и ссылку. Нажми **Подключить ноду**. Дополнительные ноды добавляются через **Панели и ноды → Добавить ноду**. Можно выбрать ещё один inbound на подключённой панели или добавить отдельную панель.
5. Открой **Настройки** и укажи контакт поддержки и ссылку на условия покупки. После этого магазин выставляет счета в Telegram Stars. Цену и пробный период можно изменить через **Тарифы**.

Навигация, подтверждения и отмена работают через кнопки. Текст вводится, когда бот запрашивает данные или задачу для ИИ. Через меню **ИИ-помощник** доступны проверка нод и админские операции. Чтобы включить помощника, укажи ключ и модель OpenAI в **Настройках**. Запросы оплачиваются по тарифу OpenAI API.

## Что получает покупатель VPN

Покупатель выбирает локацию, принимает условия, оплачивает 30 дней в Telegram Stars и получает ссылку для импорта. При продлении сохраняется та же ссылка и локация. Пробный период можно включить один раз на Telegram-аккаунт. Через **Моя подписка** видны срок действия и ссылка.

## Существующая установка Docker

Если бот уже работает через Docker, обнови файлы проекта и заново собери контейнер, сохранив том `bot-data` и локальные `.env` и `nodes.json`.

~~~bash
docker compose up -d --build
~~~

Бот подхватит старые панели из `nodes.json`. Новые панели и изменения из бота сохраняются в той же базе. Для новой установки через Compose можно создать `nodes.json` с содержимым `[]`, заполнить в `.env` только токен и ID, затем завершить настройку в Telegram.

## Проверка

~~~bash
python3 -m unittest discover -s tests -v
bash -n install.sh
~~~

Для проверки на VPS используй отдельного бота и тестовую среду [Telegram Stars](https://core.telegram.org/bots/webapps#using-bots-in-the-test-environment). Тестовый режим доступен через `TELEGRAM_TEST_MODE=1` и отдельную конфигурацию. Проверь покупку, импорт ссылки, продление и возврат. Делай резервную копию базы и настроек панели перед обновлением. Для онлайн-копии SQLite используй SQLite Backup API.
